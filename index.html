학습 타자실

학습 자료를 문장으로 바꾸고, 타자연습으로 복습하세요.
브라우저에서 실행

1. 학습 자료 입력

PDF · 이미지 · 텍스트 파일을 선택하세요
스캔한 PDF와 사진은 OCR로 글자를 읽습니다.
파일 없이 텍스트를 직접 붙여넣어도 됩니다.

2. 타자연습 문장 만들기

원문의 문단과 문장을 유지해 연습 자료로 사용합니다.

요약 모드는 중요해 보이는 문장을 고르는 기본 요약 방식입니다.
현재 버전의 요약은 별도 AI 모델을 호출하지 않는 간단한 문장 선별 방식입니다. AI 요약을 연결하려면 안전한 서버/API 설정이 추가로 필요합니다.

3. 타자연습

아래 문장을 보고 입력하세요. 문장 단위로 진행됩니다.
100%정확도
0타수(분당)
0 / 0문장
먼저 학습 자료를 입력한 뒤 ‘연습 문장 만들기’를 누르세요.
입력을 시작하면 정확도와 타수가 계산됩니다.
